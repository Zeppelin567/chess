# ♞ Chess

在浏览器里打开就能下的**双人国际象棋**，零安装。

## 运行

直接用浏览器打开 `index.html` 即可（需要联网加载 `chess.js` 规则库）。

## 玩法

- 点击己方棋子选中，绿点是合法走位，再点目标格走棋
- 将军 / 将杀 / 逼和 / 和棋自动判定
- 右侧显示吃子统计、子力领先和棋谱
- 升变自动升后

## 技术

- `index.html`：棋盘 UI + 交互逻辑（单个文件）
- 规则引擎：[chess.js](https://github.com/jhlywa/chess.js)（CDN 引入），负责合法走位、将军、将杀、易位、吃过路兵等全部规则判定
